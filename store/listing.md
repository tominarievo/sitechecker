# ストア掲載情報・審査申請の下書き

Chrome ウェブストア（デベロッパー ダッシュボード）と Edge アドオン（パートナー センター）の入力欄に、そのまま貼り付けられるようにまとめています。

## 概要（Chrome: 132文字以内）

```
閲覧中のサイトのURL・ドメイン・ページ内容を解析し、偽通販サイトや詐欺サイトの危険度を判定して、アイコンで警告します。
```

## 詳細な説明

```
「詐欺サイトチェッカー」は、閲覧中のWebサイトが偽の通販サイトや詐欺サイトである可能性を自動で判定する拡張機能です。危険度が高いサイトではツールバーのアイコンに「危険」「注意」のバッジを表示し、アイコンをクリックすると判定の根拠を確認できます。

■ 主な機能
・閲覧中のサイトを自動で判定し、危険度（0〜100%）をバッジで表示
・判定の根拠（どのドメインの特徴・ページの記載が問題か）を一覧で表示
・気になるURLを、サイトを開かずに手動で診断
・既知の偽ショップ・詐欺サイト約1.7万件のリストと照合（端末内で照合）

■ 判定に使う主な特徴
・詐欺サイトで多用される格安ドメイン（.shop / .top / .rest など）
・公式の .jp に見せかけたドメイン（.jp.net など）や、無作為な文字列のドメイン
・偽通販サイトのテンプレート特有のURL
・「特定商取引法に基づく表記」が見当たらない
・フリマアプリの出品文をコピーしたような商品説明
・「人名＋ショップ名」形式のサイト名、個人名義の振込口座、中国系フリーメールの連絡先 など

■ フィッシングの追加チェック（任意・初期設定はオフ）
設定で有効にすると、ログイン・決済フォームについて「ブランドの公式を装っているのに公式ドメインではない」「通常は別の場面で使う情報をまとめて要求している」「暗号化されていない送信先に送る」などの組み合わせを端末内で調べます。入力した内容は読み取りません。検知には限界があるため、ブラウザ標準の保護機能と併用してください。

■ プライバシー
・ページの解析はすべてブラウザ内で行い、閲覧履歴やページ内容を外部に送信しません
・広告やアクセス解析はありません
・任意で「ドメイン登録日の確認（RDAP）」を有効にした場合のみ、閲覧中サイトのドメイン名を、そのドメインを管理するレジストリに問い合わせます（初期設定はオフ）

■ ご注意
判定は自動的な推定です。正規のサイトを危険と判定したり、詐欺サイトを見逃したりする場合があります。初めて利用する通販サイトでは、運営者情報や支払い方法もあわせてご確認ください。

ソースコード（GPL-3.0）: https://github.com/tominarievo/sitechecker
```

## 審査用の申告（Chrome「プライバシーへの取り組み」タブ／Edge も同様）

### 単一用途の説明

```
閲覧中または入力されたWebサイトが、偽通販サイト・詐欺サイトである可能性を判定し、利用者に警告すること。
```

### 権限が必要な理由

| 権限 | 理由（そのまま貼り付け可） |
|---|---|
| `tabs` | 閲覧中のタブのURLを取得して危険度を判定し、タブごとにツールバーのバッジを更新するため。 |
| `storage` | 利用者の設定と、ドメイン登録日の照会結果（キャッシュ）、タブごとのページ解析結果を端末内に保存するため。 |
| ホスト権限（コンテンツスクリプト: `http://*/*`, `https://*/*`） | 閲覧中のページの本文を端末内で解析し、「特定商取引法に基づく表記」の有無や、偽通販サイトに特有の記載を検出するため。また、利用者が有効にした場合は、入力フォームの種類と送信先を端末内で調べ、フィッシングの特徴を検出するため（入力値は読み取りません）。どのサイトが詐欺サイトかは事前に分からないため、すべてのサイトで動作する必要があります。解析結果は外部に送信しません。 |

### リモートコード

```
使用していません。すべてのコードは拡張機能のパッケージに含まれています。
```

### データの使用

申告の考え方（最終判断は提出者が行ってください）:

- ページ内容・URLは**端末内で処理するだけで、開発者のサーバーには送信しない**ため、「収集するデータ」には該当しないと考えられます。
- ただし、RDAP 機能を有効にした場合は**閲覧中のドメイン名が第三者（ドメインのレジストリ）に送信される**ため、慎重を期すなら「ウェブ履歴」にチェックを入れ、用途を「拡張機能の中核機能（詐欺サイトの判定）」として申告するのが安全です。
- 次の3項目の誓約にはすべて該当します。
  - 承認されている用途以外で、ユーザーデータを第三者に販売・転送しない
  - 拡張機能の単一用途と関係のない目的で、ユーザーデータを使用・転送しない
  - 信用力の判断や融資の目的で、ユーザーデータを使用・転送しない
