## 概要（Chrome: 132文字以内）

```
閲覧中のサイトのURL・ドメイン・ページ内容からリスク要因を検出し、リスクスコアと判定の根拠を表示して、アイコンで警告します。
```

## 詳細な説明

```
「詐欺サイトチェッカー」は、閲覧中のWebサイトのURL・ドメイン・ページ内容から、偽通販などのリスク要因を検出する拡張機能です。検出した要因に基づくリスクスコアが高い場合、ツールバーのアイコンに「危険」「注意」のバッジを表示します。アイコンをクリックすると点数と判定の根拠を確認できます。

■ 主な機能
・閲覧中のサイトを自動で解析し、リスクスコア（0〜100点）をポップアップで表示。40点以上で「注意」、80点以上で「危険」のバッジを表示
・判定の根拠（どのドメインの特徴・ページの記載が問題か）を一覧で表示
・気になるURLを、サイトを開かずに手動で診断
・既知の偽ショップ・詐欺サイト約1.9万件のリストと照合（端末内で照合）
・JPCERT/CCのフィッシングURL公表履歴、CCJ・消費者庁の悪質通販公表情報と照合。出典・確認日・区分を表示します。掲載された当時の情報であり、現在の稼働状況は未確認です

■ 判定に使う主な特徴
・詐欺サイトで多用される格安ドメイン（.shop / .top / .rest など）
・公式の .jp に見せかけたドメイン（.jp.net など）や、無作為な文字列のドメイン
・偽通販サイトのテンプレート特有のURL
・「特定商取引法に基づく表記」が見当たらない
・フリマアプリの出品文をコピーしたような商品説明
・「人名＋ショップ名」形式のサイト名、個人名義の振込口座、中国系フリーメールの連絡先 など

■ フィッシングの追加チェック（任意・初期設定はオフ）
設定で有効にすると、ログイン・決済フォームについて「ブランドの公式を装っているのに公式ドメインではない」「通常は別の場面で使う情報をまとめて要求している」「暗号化されていない送信先に送る」などの組み合わせを端末内で調べます。入力した内容は読み取りません。検知には限界があるため、ブラウザ標準の保護機能と併用してください。

■ プライバシー
・ページの解析はブラウザ内で行い、ページ内容を外部に送信しません。タブごとのURLと判定結果（根拠に含まれる短い抜粋を含む）を端末内に一時保存し、タブを閉じたとき、またはブラウザ終了時に削除します
・閲覧先URLやページ内容は送信しません。ブラックリストはGitHub Pagesから定期取得し、その要求には通常の接続情報（IPアドレス等）が含まれる場合があります
・広告やアクセス解析はありません
・任意で「ドメイン登録日の確認（RDAP）」を有効にした場合のみ、閲覧中・手動入力されたURLの登録ドメイン名を、そのドメインを管理するレジストリに問い合わせ、結果を端末内にキャッシュします（初期設定はオフ）

■ ご注意
リスクスコアはルールによる加点の目安で、詐欺である確率ではありません。低い点数や判定除外も、個々のページ・出品者の安全性を保証しません。正規のサイトを危険と判定したり、詐欺サイトを見逃したりする場合があります。運営者情報や支払い方法もあわせてご確認ください。

ソースコード（GPL-3.0）: https://github.com/tominarievo/sitechecker
```

## 審査用の申告（Chrome「プライバシーへの取り組み」タブ／Edge も同様）

### 単一用途の説明

```
閲覧中または入力されたWebサイトが、偽通販サイト・詐欺サイトである可能性を判定し、利用者に警告すること。
```

### 権限が必要な理由

| 権限 | 理由（そのまま貼り付け可） |
|---|---|
| `tabs` | 閲覧中のタブのURLを取得してリスク要因を検出し、タブごとにツールバーのバッジを更新するため。 |
| `storage` | 利用者の設定、RDAPキャッシュ、検証済みブラックリストを端末内に保存し、タブごとのURL・ページ解析結果・追加フィッシング判定結果を一時保存するため。判定根拠に含まれる短い抜粋を保存する場合がありますが、ページ本文全体や入力値は保存しません。 |
| `alarms` | ブラックリストの更新確認を1日ごとにスケジュールするため。 |
| ホスト権限（`https://tominarievo.github.io/*`） | HaGeZi Fakeの配信用JSONをHTTPSで取得するため。閲覧先URLやページ内容は要求に含めず、取得データはハッシュと形式を検証して端末内に保存します。 |
| ホスト権限（コンテンツスクリプト: `http://*/*`, `https://*/*`） | 閲覧中のページの本文を端末内で解析し、「特定商取引法に基づく表記」の有無や、偽通販サイトに特有の記載を検出するため。また、利用者が有効にした場合は、入力フォームの種類と送信先を端末内で調べ、フィッシングの特徴を検出するため（入力値は読み取りません）。どのサイトが詐欺サイトかは事前に分からないため、すべてのサイトで動作する必要があります。解析結果は外部に送信しません。 |

### リモートコード

```
使用していません。すべてのコードは拡張機能のパッケージに含まれています。
```

### データの使用

申告に用いる実装上の事実（提出画面の定義に合わせて申告してください）:

- タブのURL（パス・クエリを含む）と判定結果を端末内に一時保存します。ページ解析の根拠には、店名・運営者名・口座名義などの短い抜粋が含まれる場合があります。ページ本文全体や利用者の入力値は保存しません。
- 閲覧先URL・ページ内容を開発者には送信しません。ブラックリストの取得要求はGitHub Pagesに送信され、通常の接続情報（IPアドレス等）が伝わる場合があります。RDAP 有効時は閲覧中・手動入力されたURLの登録ドメイン名を第三者のレジストリに送信します。「一切保存しない」「第三者への送信なし」とは申告しないでください。
- URL・ドメイン名とページ内容の取り扱いを、該当するデータ項目と中核機能としての用途に記載し、プライバシーポリシー・掲載文・実装で説明を一致させてください。
- 次の3項目の誓約にはすべて該当します。
  - 承認されている用途以外で、ユーザーデータを第三者に販売・転送しない
  - 拡張機能の単一用途と関係のない目的で、ユーザーデータを使用・転送しない
  - 信用力の判断や融資の目的で、ユーザーデータを使用・転送しない
