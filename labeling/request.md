# 外部への依頼の進め方（依頼者向け）

## 依頼の流れ

1. 依頼票を作る（`tools/label-package.js --make`）
   - `crowd/tasks.csv` … 作業者に渡す表
   - `crowd/key.json` … 照合用。**作業者には渡さない**
2. クラウドソーシング（クラウドワークス、ランサーズ等）で募集する。下の募集文をそのまま使えます
3. **同じ表を3人以上に**依頼する（多数決と、作業者の正確さの確認のため）
4. 回収した回答を集計する（`tools/label-package.js --import`）
5. 精度を評価する（`tests/content-eval.js --with-blocklist --target`）

## 募集文（例）

```
【タイトル】Webページのスクリーンショットを見て、通販サイトの種類を判定する作業（約○件）

【内容】
表に記載されたスクリーンショット画像を見て、そのページが
「偽の通販サイト」「正規の通販サイト」「通販サイトではない」「判断できない」
のどれにあたるかを選んで記入していただく作業です。

・1件あたり10〜20秒程度です
・判断の目安をまとめた手順書をお渡しします
・作業は画像の閲覧だけで、サイトへのアクセスや会員登録は不要です
  （安全のため、判定対象のサイトそのものには絶対にアクセスしないでください）
・答えが分かっている確認用の問題を含みます

【納品物】
記入済みの表（CSV または Excel）。作業者IDの列（worker_id）にご自身の名前またはIDを入れてください。

【目的】
詐欺サイトを見分けるブラウザ拡張機能の精度を評価するためです。
```

## 依頼前の確認事項

- **件数と費用**: 判定対象600件 ＋ 確認用60件 × 3人 ＝ 約2,000判定。1件10〜20秒として、1人あたり2〜4時間程度です
- **渡す情報**: スクリーンショット画像の URL、ドメイン名（無害化表記）、ページタイトルだけです。詐欺サイトの URL やこちらの判定結果は渡しません
- **扱う画像**: 偽サイトの画像には、実在ブランドのロゴや商品写真が含まれます。作業者に「画像の転載・保存をしない」ことを依頼文に含めると安心です
- **プラットフォームの規約**: 詐欺サイトの画像を扱う作業が、利用するサービスの規約上問題ないかを事前に確認してください
