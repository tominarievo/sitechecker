詐欺サイトチェッカー プライバシーポリシー

制定日: 2026年10月7日

ブラウザ拡張機能「詐欺サイトチェッカー」（以下「本拡張機能」）は、閲覧中のWebサイトが悪質な通販サイト・詐欺サイトである可能性を判定するためのツールです。本拡張機能は、利用者の個人情報や閲覧履歴を収集・保存・販売しません。

1. 拡張機能内で扱う情報

情報用途外部への送信
閲覧中のタブのURLURL・ドメインの特徴から危険度を判定し、アイコンのバッジに表示するためしません
閲覧中のページの本文・リンク「特定商取引法に基づく表記」の有無などを判定するため。解析はブラウザ内で完結し、本文は保存しませんしません
手動チェック欄に入力したURL入力されたURLの危険度を判定するためしません（RDAP 有効時は登録ドメイン名のみ下記のとおり送信）

2. フィッシングの追加チェック（初期設定はオフ）

ポップアップの設定で「フィッシングの追加チェックを有効にする」をオンにした場合に限り、閲覧中のページの入力フォームについて、入力欄の種類（パスワード欄・カード番号欄など）、フォームの送信先、周辺の表示文言を調べます。

  • 解析はブラウザ内で完結し、外部への通信は一切行いません（この機能のために、外部のサーバーやAPIに問い合わせることはありません）。
  • 利用者が入力した内容（パスワード、カード番号、ワンタイムパスワード等）は読み取りません。
  • 保存するのは判定の根拠（該当したチェックの種類、関係するドメイン名、点数）だけで、ページの本文や入力値は保存しません。
  • 無効にすると、保存済みの判定結果を削除します。

3. 外部への通信（ドメイン登録日の確認・初期設定はオフ）

ポップアップの設定で「ドメイン登録日を確認する（RDAP）」を有効にした場合に限り、次の通信を行います。

  • IANA（data.iana.org）: TLD（.com など）ごとの RDAP サーバーの一覧を取得します（1日1回程度）。閲覧中のサイトの情報は含みません。
  • 各TLDのレジストリ（ドメイン登録管理機関）の RDAP サーバー: 閲覧中のサイトの登録ドメイン名のみ（例: example.com）を送信し、登録日を取得します。URLのパス、ページの内容、Cookie、利用者を識別する情報は送信しません。

この機能は初期設定では無効です。いつでも設定から無効にでき、無効にすると保存済みの照会結果もすべて削除します。

4. 端末内に保存する情報

  • 設定（RDAP の有効・無効）
  • RDAP の照会結果（ドメイン名と登録日）: 同じドメインへの再照会を減らすため、照会から最長7日間保存します（照会に失敗した場合は最長6時間）。期限を過ぎた記録は、ブラウザの起動時と拡張機能の動作時（1時間に1回まで）に自動で削除します。
  • RDAP サーバーの一覧（IANA から取得したもの）: 最長1日間保存し、期限を過ぎたものは上記と同様に削除します。
  • タブごとのページ解析結果（判定の根拠のみ。ページの本文は含みません）: タブを閉じたとき、またはブラウザを終了したときに消去されます。
  • フィッシングの追加チェックのタブごとの結果（判定の根拠と点数のみ。入力値やページの本文は含みません）: タブを閉じたとき、ブラウザを終了したとき、またはこの機能を無効にしたときに消去されます。

これらはブラウザの拡張機能用ストレージにのみ保存され、開発者を含む第三者に送信されることはありません。本拡張機能をアンインストールすると削除されます。

5. 同梱データ

既知の詐欺サイトとの照合には、拡張機能に同梱したリスト（HaGeZi DNS Blocklists、GPL-3.0）を使用します。フィッシングの追加チェックでは、同梱した Public Suffix List（MPL-2.0）とブランドの公式ドメインの対応表を使用します。いずれも照合は端末内で行い、外部への問い合わせは行いません。

6. 第三者への提供・広告

本拡張機能は、利用者の情報を第三者に提供・販売しません。広告の表示や、利用状況の分析（アクセス解析）も行いません。

7. 判定結果について

判定は自動的な推定であり、正確性を保証するものではありません。正規のサイトを危険と判定したり、詐欺サイトを見逃したりする場合があります。

8. お問い合わせ・改定

本ポリシーに関するお問い合わせは、GitHub の Issues からお願いします。本ポリシーを改定する場合は、このページで公表します。

Privacy Policy — Scam Site Checker

Effective: October 7, 2026

The "Scam Site Checker" browser extension estimates whether the website you are viewing may be a fraudulent online shop or scam site. It does not collect, store, sell, or share your personal information or browsing history.

Data handled locally

  • URL of the active tab — analyzed locally to calculate a risk score shown on the toolbar badge. Not transmitted.
  • Page text and links — analyzed locally (e.g., to check for a legally required seller disclosure). Not stored and not transmitted.
  • URLs entered in the manual check form — analyzed locally. Not transmitted (except the registrable domain when RDAP is enabled, see below).

Additional phishing check (off by default)

Only if you enable "additional phishing check" in the popup settings, the extension inspects the forms on the page you are viewing: the kinds of input fields (password, card number, etc.), where the form submits, and the surrounding visible text. The analysis runs entirely in your browser and makes no network requests. The extension never reads what you type (passwords, card numbers, one-time codes). Only the detected risk factors (check type, related domain names, points) are kept, and they are deleted when you disable the feature.

Network requests (domain age check, off by default)

This feature is off by default. Only if you enable "Check domain registration date (RDAP)" in the popup settings, the extension fetches the RDAP server list from IANA (data.iana.org) and sends only the registrable domain name (e.g., example.com) to the RDAP server of the registry that manages that top-level domain. No paths, page content, cookies, or identifiers are sent.

Local storage

  • Settings (whether RDAP is enabled).
  • Cached RDAP results (domain name and registration date): kept for up to 7 days after the lookup (up to 6 hours for failed lookups) to avoid repeated queries. Expired records are deleted automatically when the browser starts and while the extension is running (at most once per hour). Disabling RDAP deletes all cached results.
  • RDAP server list obtained from IANA: kept for up to 1 day and deleted the same way when expired.
  • Per-tab analysis results (detected risk factors only, never the page text): cleared when the tab is closed or the browser exits.
  • Per-tab phishing check results (risk factors and points only, never input values or page text): cleared when the tab is closed, the browser exits, or the feature is disabled.

All of the above is stored only in the browser's extension storage, is never sent to the developer or third parties, and is removed when the extension is uninstalled.

No sharing, no ads, no analytics

The extension does not sell or share data with third parties, show ads, or use analytics.
